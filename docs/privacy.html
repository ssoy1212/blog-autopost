개인정보처리방침

Quiet Journals Autopost · 시행일 2026년 10월 28일

1. 적용 대상

이 방침은 블로그 「내향인의 기록」 운영자가 개인적으로 사용하는 글 게시 도구 "Quiet Journals Autopost"(이하 "도구")에 적용됩니다. 도구의 사용자는 운영자 한 사람뿐입니다.

2. 접근하는 Google 사용자 데이터

도구는 운영자 본인의 Google 계정에 대해 Blogger 권한 (https://www.googleapis.com/auth/blogger)만 요청합니다. 다른 Google 서비스(Gmail, Drive, 연락처 등)의 데이터에는 접근하지 않으며, 운영자 외 다른 사람의 Google 계정 데이터에도 접근하지 않습니다.

3. 데이터 사용 방법

  • Blogger 권한은 운영자 본인의 블로그에 글 초안을 작성하는 용도로만 사용합니다.
  • 글 초안을 만들기 위해 주제와 키워드를 Anthropic Claude API로 보냅니다. 이때 Google 계정 정보나 Blogger에서 읽은 데이터는 보내지 않습니다.
  • Google 사용자 데이터를 광고, 판매, 프로파일링, AI 모델 학습에 사용하지 않습니다.

4. 저장 및 보관

도구는 Google 사용자 데이터를 별도의 데이터베이스에 저장하지 않습니다. 인증에 필요한 토큰은 운영자가 관리하는 GitHub 저장소의 암호화된 Secrets에만 보관되며, 공개되지 않습니다.

5. 공유

Google 사용자 데이터를 제3자와 공유하거나 판매하지 않습니다.

6. 권한 철회

운영자는 언제든지 Google 계정의 서드파티 앱 및 서비스 설정에서 도구의 접근 권한을 철회할 수 있습니다.

7. Google API 서비스 사용자 데이터 정책 준수

도구가 Google API에서 받은 정보를 사용하는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 포함하여 해당 정책을 준수합니다.

8. 문의 및 변경

문의는 이 도구의 GitHub 저장소 Issues 탭을 이용해 주세요. 이 방침이 변경되면 이 페이지에 갱신된 내용과 시행일을 게시합니다.

Privacy Policy (English)

Quiet Journals Autopost is a personal tool used only by the owner of the blog "Quiet Journals". It requests only the Blogger scope (https://www.googleapis.com/auth/blogger) for the owner's own Google account and uses it solely to create draft posts on the owner's own blog. It does not access other Google services or any other user's data. Topics and keywords are sent to the Anthropic Claude API to draft posts; no Google account data is sent. Google user data is not stored in any database, sold, shared with third parties, or used for advertising or AI model training. OAuth tokens are kept only in encrypted GitHub Secrets controlled by the owner. Access can be revoked at any time at Google Account permissions. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: the Issues tab of this tool's GitHub repository.
