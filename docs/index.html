Quiet Journals Autopost

블로그 「내향인의 기록」 운영자가 개인적으로 사용하는 글 게시 도구

무엇을 하는 도구인가요?

운영자 본인의 Blogger 블로그에 글 초안을 자동으로 올리는 개인용 스크립트입니다. 미리 정해둔 주제 목록을 바탕으로 AI(Anthropic Claude API)가 글 초안을 작성하고, Google Blogger API를 통해 운영자 본인의 블로그에 초안으로 저장합니다. 운영자는 초안을 검토한 뒤 직접 발행합니다.

누가 사용하나요?

이 도구는 운영자 한 사람만 사용합니다. 외부 사용자의 가입이나 로그인 기능은 없으며, 다른 사람의 Google 계정 데이터에는 접근하지 않습니다.

Google 데이터 사용

이 도구는 운영자 본인의 Google 계정으로 Blogger 권한만 요청하며, 운영자의 블로그에 글을 작성하는 용도로만 사용합니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.

English summary. Quiet Journals Autopost is a personal tool used only by the owner of the Blogger blog "Quiet Journals". It drafts posts with the Anthropic Claude API and saves them as drafts to the owner's own blog via the Google Blogger API. It has no public sign-up and does not access any other user's Google data. See the Privacy Policy.
